# Pstack 0.15.25 port decisions

Reviewed on 2026-10-17 against immutable upstream commit
[`101b274dd991f694e1f7024be2157e5f3adf07de`](https://github.com/cursor/plugins/tree/101b274dd991f694e1f7024be2157e5f3adf07de/pstack).
The previous baseline was pstack 0.15.5 at `c47b12849e43f18d5c374c7069c744cc55b0ea00`. The range holds 41 pstack commits and 110 changed paths.

## Port policy

Apply portable upstream additions and removals. Keep every skill harness-neutral and agent-neutral: no host tool names, subagent types, fixed model identifiers or families, host configuration paths, or host slash commands. Name sibling skills with an installed check and a complete inline fallback. Preserve the solo-agent communication and Git-authority boundaries, independent package layout, and unrelated local changes.

Upstream now picks a reasoning level and speed per subagent. Locally that rule lives once, in the engineering-mode Delegation section, and only steps between reasoning profiles the host confirms for the configured model. It never changes the model family or builds an identifier. Routed skills point to it with one sentence and fall back to the configured profile.

## Local fix found during review

Prettier renumbers ordered Markdown lists. It had rewritten the stable `unslop` rule ids 5 and 22 to 4 and 21. The lists now carry `<!-- prettier-ignore -->`, and a behavior scenario asserts the ids. Removing the marker and formatting reproduces the renumbering, which the scenario rejects.
