# adversarial-review

Run independent read-only reviewers against the same code and intent, then apply lead judgment to surface high-confidence blind spots without changing the code.

## Install

```bash
bunx skills@latest add petalas/skills --skill adversarial-review -g -y
```

## Usage

```text
Use $adversarial-review for this task.
```

This plugin adapts material from pstack. The installed skill includes the full upstream notice and exact provenance.
