# auditable-run

Design and execute an evidence-driven local workflow for a large task when no focused playbook fits.

## Install

```bash
bunx skills@latest add petalas/skills --skill auditable-run -g -y
```

## Usage

```text
Use $auditable-run for this task.
```

This plugin adapts material from pstack. The installed skill includes the full upstream notice and exact provenance.
