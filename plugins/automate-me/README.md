# automate-me

Create or update a personal mode skill from the user's stated preferences and workspace-scoped conversation history.

## Install

```bash
bunx skills@latest add petalas/skills --skill automate-me -g -y
```

## Usage

```text
Use $automate-me for this task.
```

This plugin adapts material from pstack. The installed skill includes the full upstream notice and exact provenance.
