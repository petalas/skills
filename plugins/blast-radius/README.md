# blast-radius

Find what a change could break outside its diff, identify the safety facts it depends on, and prove those facts with executable evidence when practical.

## Install

```bash
bunx skills@latest add petalas/skills --skill blast-radius -g -y
```

## Usage

```text
Use $blast-radius for this task.
```

This plugin adapts material from pstack. The installed skill includes the full upstream notice and exact provenance.
