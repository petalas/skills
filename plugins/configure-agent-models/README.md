# configure-agent-models

Record host-neutral model preferences for internal agent roles using only models available in the current environment.

## Install

```bash
bunx skills@latest add petalas/skills --skill configure-agent-models -g -y
```

## Usage

```text
Use $configure-agent-models for this task.
```

This plugin adapts material from pstack. The installed skill includes the full upstream notice and exact provenance.
