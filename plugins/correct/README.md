# correct

Find the mistakes agents keep repeating in this repo and make each one impossible. Try architecture first, then types, then a lint whose error names the fix, then a test, and write docs last. Prove each check fails on a real past mistake. Repeat this each time the user corrects you.

## Install

```bash
bunx skills@latest add petalas/skills --skill correct -g -y
```

## Usage

```text
Use $correct for this task.
```

This plugin adapts material from pstack. The installed skill includes the full upstream notice and exact provenance.
