# create-verification-skill

Create a project-local skill that drives an app through its real user surface and captures proof.

## Install

```bash
bunx skills@latest add petalas/skills --skill create-verification-skill -g -y
```

## Usage

```text
Use $create-verification-skill for this task.
```

This plugin adapts material from pstack. The installed skill includes the full upstream notice and exact provenance.
