# Session pickup

Use to resume work from a local transcript, resume note, branch, worktree, or prior task summary.

1. Read the prior trail from the exact path or task the user placed in scope. For a long transcript, use a read-only subagent to reduce it to decisions, evidence, and pending work.
2. Reconstruct the local branch, worktree, changed files, validation state, and open plan items.
3. Compare completed work with the original goal. Name the precise resume point. Do not redo finished work just to regain confidence.
4. Verify inherited claims at the boundary needed for the next step. A prior summary alone is not proof.
5. Route remaining work to the matching engineering playbook.

Return what was inherited, what required rechecking, the resume point, and the selected next playbook.
