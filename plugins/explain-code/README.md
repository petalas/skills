# explain-code

Explain code plainly by combining how it works with the evidence for why it has that shape. Use for teaching a change, subsystem, or unfamiliar code path.

## Install

```bash
bunx skills@latest add petalas/skills --skill explain-code -g -y
```

## Usage

```text
Use $explain-code for this task.
```

This plugin adapts material from pstack. The installed skill includes the full upstream notice and exact provenance.
