# in-your-own-words

Restate in your own words what you think the user's goals are and what problem they're trying to solve.

## Install

```bash
bunx skills@latest add petalas/skills --skill in-your-own-words -g -y
```

## Usage

```text
Use $in-your-own-words for this task.
```

This plugin adapts material from pstack. The installed skill includes the full upstream notice and exact provenance.
