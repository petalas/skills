# ketchup

Catch the user up on what changed in this chat since their last message, in a few plain sentences and small visuals. Give each action item just enough context to make the call.

## Install

```bash
bunx skills@latest add petalas/skills --skill ketchup -g -y
```

## Usage

```text
Use $ketchup for this task.
```

This plugin adapts material from pstack. The installed skill includes the full upstream notice and exact provenance.
