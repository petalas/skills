# $knowledge-audit

Audit the knowledge system of the project in the current working directory using the `knowledge-audit` skill. Run the quick check on the project's agent instructions file (`AGENTS.md`, or `CLAUDE.md` where that is what the project uses) first: a "Required Reading" routing table mapping file patterns to docs, and a "When You Struggle" heading. If both pass, report that the knowledge system is current and stop. Otherwise run the full audit (routing table coverage, capture process and quality bar, domain docs and LEARNINGS.md, instructions file size, optional Active Warnings section), report a pass/fail checklist with an overall rating of Compliant, Partially compliant, or Not set up, and offer to set the system up or migrate legacy artifacts. Do not edit anything until the user approves the specific changes, and do not commit.
