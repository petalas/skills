# $knowledge-migrate-all

Find every project that needs knowledge system setup or migration using the `knowledge-migrate-all` skill. Use the directories the user named as search roots; if none were named, ask which directory trees to scan before doing anything else, suggesting common project parents such as `~/git`, `~/projects`, `~/work`, and `~/src`. Under each root, find version-controlled project roots that contain an agent instructions file (`AGENTS.md`, or `CLAUDE.md` where that is what the project uses), run the two quick checks on each (a "Required Reading" routing table and a "When You Struggle" heading), and report a status table of Current, Needs update, and Setup needed with the `knowledge-audit` action that applies to each. This is read-only discovery: do not edit, create, or commit anything in any project.
