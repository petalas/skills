# maintain-verification-skill

Audit a project verification skill against source and every mapped user-facing feature, then apply proven local corrections.

## Install

```bash
bunx skills@latest add petalas/skills --skill maintain-verification-skill -g -y
```

## Usage

```text
Use $maintain-verification-skill for this task.
```

This plugin adapts material from pstack. The installed skill includes the full upstream notice and exact provenance.
