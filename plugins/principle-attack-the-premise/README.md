# principle-attack-the-premise

Apply when two or more fixes that share one premise have failed the same gate. Write the premise down and test it directly before you write another fix that assumes it.

## Install

```bash
bunx skills@latest add petalas/skills --skill principle-attack-the-premise -g -y
```

## Usage

```text
Use $principle-attack-the-premise for this task.
```

This plugin adapts material from pstack. The installed skill includes the full upstream notice and exact provenance.
