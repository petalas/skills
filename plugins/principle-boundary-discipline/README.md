# principle-boundary-discipline

Apply when wiring validation, error handling, or framework adapters. Concentrate guards at system boundaries (CLI, config, network, external APIs); trust internal types and keep business logic in pure functions.

## Install

```bash
bunx skills@latest add petalas/skills --skill principle-boundary-discipline -g -y
```

## Usage

```text
Use $principle-boundary-discipline for this task.
```

This plugin adapts material from pstack. The installed skill includes the full upstream notice and exact provenance.
