# principle-experience-first

Apply when product, UX, or feature-scope tradeoffs come up. Choose user delight over implementation convenience; ship fewer polished features over more rough ones.

## Install

```bash
bunx skills@latest add petalas/skills --skill principle-experience-first -g -y
```

## Usage

```text
Use $principle-experience-first for this task.
```

This plugin adapts material from pstack. The installed skill includes the full upstream notice and exact provenance.
