# principle-fix-root-causes

Apply when debugging. Trace each symptom back to the first place the system went wrong and fix it there. A guard is a fix only when the state it handles is legitimate.

## Install

```bash
bunx skills@latest add petalas/skills --skill principle-fix-root-causes -g -y
```

## Usage

```text
Use $principle-fix-root-causes for this task.
```

This plugin adapts material from pstack. The installed skill includes the full upstream notice and exact provenance.
