# principle-foundational-thinking

Apply before writing logic: choosing core types and data structures, sequencing scaffold-vs-feature work, asking what concurrent actors share. Get the data structures right so downstream code becomes obvious.

## Install

```bash
bunx skills@latest add petalas/skills --skill principle-foundational-thinking -g -y
```

## Usage

```text
Use $principle-foundational-thinking for this task.
```

This plugin adapts material from pstack. The installed skill includes the full upstream notice and exact provenance.
