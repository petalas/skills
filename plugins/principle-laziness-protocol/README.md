# principle-laziness-protocol

Apply when refactoring, evaluating diff size, or tempted to add abstractions, layers, or signal threading. Bias toward deletion and the smallest change that solves the problem.

## Install

```bash
bunx skills@latest add petalas/skills --skill principle-laziness-protocol -g -y
```

## Usage

```text
Use $principle-laziness-protocol for this task.
```

This plugin adapts material from pstack. The installed skill includes the full upstream notice and exact provenance.
