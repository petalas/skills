# principle-local-autonomy

Apply when reversible local work can proceed without a permission pause. Keep agents autonomous inside the workspace while reserving external communication and consequential actions for the user.

## Install

```bash
bunx skills@latest add petalas/skills --skill principle-local-autonomy -g -y
```

## Usage

```text
Use $principle-local-autonomy for this task.
```

This plugin adapts material from pstack. The installed skill includes the full upstream notice and exact provenance.
