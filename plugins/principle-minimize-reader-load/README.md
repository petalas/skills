# principle-minimize-reader-load

Apply when reviewing or shaping code that's hard to trace. Count layers between question and answer, and hidden state in the reader's head; collapse one-caller wrappers and shrink mutable scope.

## Install

```bash
bunx skills@latest add petalas/skills --skill principle-minimize-reader-load -g -y
```

## Usage

```text
Use $principle-minimize-reader-load for this task.
```

This plugin adapts material from pstack. The installed skill includes the full upstream notice and exact provenance.
