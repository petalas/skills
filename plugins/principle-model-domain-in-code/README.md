# principle-model-domain-in-code

Apply when writing stateful logic, or when code branches a lot or repeats a shape assumption across files. Encode the domain in a structure instead of scattered conditionals.

## Install

```bash
bunx skills@latest add petalas/skills --skill principle-model-domain-in-code -g -y
```

## Usage

```text
Use $principle-model-domain-in-code for this task.
```

This plugin adapts material from pstack. The installed skill includes the full upstream notice and exact provenance.
