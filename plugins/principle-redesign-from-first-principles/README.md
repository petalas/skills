# principle-redesign-from-first-principles

Apply when integrating a new requirement into an existing design. Redesign as if the requirement had been a foundational assumption from day one, instead of bolting it on.

## Install

```bash
bunx skills@latest add petalas/skills --skill principle-redesign-from-first-principles -g -y
```

## Usage

```text
Use $principle-redesign-from-first-principles for this task.
```

This plugin adapts material from pstack. The installed skill includes the full upstream notice and exact provenance.
