# principle-replace-internal-apis-atomically

Apply when introducing a new internal API while old callers still exist. Migrate callers and delete the old API in the same wave instead of preserving compatibility layers.

## Install

```bash
bunx skills@latest add petalas/skills --skill principle-replace-internal-apis-atomically -g -y
```

## Usage

```text
Use $principle-replace-internal-apis-atomically for this task.
```

This plugin adapts material from pstack. The installed skill includes the full upstream notice and exact provenance.
