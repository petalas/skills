# principle-sequence-verifiable-units

Apply to multi-step work such as sweeps, migrations, and runs of similar edits. Break work into small units that each end in a verifiable state, check each before the next, and order authorized delivery so the sequence proves itself.

## Install

```bash
bunx skills@latest add petalas/skills --skill principle-sequence-verifiable-units -g -y
```

## Usage

```text
Use $principle-sequence-verifiable-units for this task.
```

This plugin adapts material from pstack. The installed skill includes the full upstream notice and exact provenance.
