# principle-test-behavior-not-implementation

Apply when you write, change, or keep a test. Assert what the code's users can observe, so that the test fails when that behavior breaks and keeps passing when only the internals change.

## Install

```bash
bunx skills@latest add petalas/skills --skill principle-test-behavior-not-implementation -g -y
```

## Usage

```text
Use $principle-test-behavior-not-implementation for this task.
```

This plugin adapts material from pstack. The installed skill includes the full upstream notice and exact provenance.
