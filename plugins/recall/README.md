# recall

Reconstruct recent solo-development context from the current host's accessible task history, repository history, local docs, and live workspace state, then return a concise current-state brief.

## Install

```bash
bunx skills@latest add petalas/skills --skill recall -g -y
```

## Usage

```text
Use $recall for this task.
```

This plugin adapts material from pstack. The installed skill includes the full upstream notice and exact provenance.
