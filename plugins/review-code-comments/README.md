# review-code-comments

Review source-code comments for noise, stale explanations, suppressions, and constraints that should be encoded in code, then apply only authorized local cleanups.

## Install

```bash
bunx skills@latest add petalas/skills --skill review-code-comments -g -y
```

## Usage

```text
Use $review-code-comments for this task.
```

This plugin adapts material from pstack. The installed skill includes the full upstream notice and exact provenance.
