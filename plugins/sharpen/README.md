# sharpen

Sharpen a task before starting: the expert approach, what the user is really after, and the right level of specification.

## Install

```bash
bunx skills@latest add petalas/skills --skill sharpen -g -y
```

## Usage

```text
Use $sharpen for this task.
```

This plugin adapts material from pstack. The installed skill includes the full upstream notice and exact provenance.
