# show-me-your-work

Keep a local, reviewable TSV decision trail for long-running, unattended, or multi-phase work.

## Install

```bash
bunx skills@latest add petalas/skills --skill show-me-your-work -g -y
```

## Usage

```text
Use $show-me-your-work for this task.
```

This plugin adapts material from pstack. The installed skill includes the full upstream notice and exact provenance.
