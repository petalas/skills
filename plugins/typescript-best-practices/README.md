# typescript-best-practices

TypeScript best practices. Use when reading or editing any .ts or .tsx file.

## Install

```bash
bunx skills@latest add petalas/skills --skill typescript-best-practices -g -y
```

## Usage

```text
Use $typescript-best-practices for this task.
```

This plugin adapts material from pstack. The installed skill includes the full upstream notice and exact provenance.
