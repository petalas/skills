# Incident and postmortem context

Search only read-only sources already authorized for the task:

- **Issue tracking**: look for tickets labeled `incident`, `sev-*`, `postmortem-action-item`, `reliability`.
- **Git**: commits with messages like "fix for incident", "add defensive check", "revert" followed by "re-apply with..." are strong signals.

Never search workplace chat or private correspondence. Never update an incident, issue, dashboard, or external record.
