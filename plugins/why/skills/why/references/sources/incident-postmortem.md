# Incident and postmortem context

This is a cross-cutting angle for defensive code such as retries, timeouts, rate limits, feature flags, guards, and recovery paths.

Search only read-only sources already authorized for the task:

- repository commits, reverts, tests, and local postmortem files;
- observability incidents, dashboards, metrics, logs, and traces;
- error-tracking issues, events, stack traces, and release windows;
- product events that measure the visible failure or recovery path.

Corroboration across independent lanes is strong evidence, but time correlation alone does not prove causation. Fetch the full local or read-only incident record when available. Record missing records as gaps.

Never search workplace chat or private correspondence. Never update an incident, issue, dashboard, or external record.
