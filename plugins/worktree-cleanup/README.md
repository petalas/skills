# worktree-cleanup

Audit git worktrees and local development caches, then remove only targets proven unused and recoverable.

## Install

```bash
bunx skills@latest add petalas/skills --skill worktree-cleanup -g -y
```

## Usage

```text
Use $worktree-cleanup for this task.
```

This plugin adapts material from pstack. The installed skill includes the full upstream notice and exact provenance.
